# 🚀 DevOps Journey: Bootcamp 2024/25

Welcome to my DevOps learning repository! This project serves as a comprehensive documentation of my journey through the DevOps lifecycle, focusing on automation, infrastructure as code, and continuous integration/delivery.

---

## 📌 Project Overview
The goal of this bootcamp is to master the tools and methodologies required to bridge the gap between development and operations. Each module contains hands-on scripts, configuration files, and documentation.

## 🛠️ Tech Stack & Tools
Inside this repository, you will find projects using:
* **OS & Scripting:** Linux (Ubuntu), Bash Scripting
* **Containerization:** Docker, Docker Compose
* **Orchestration:** Kubernetes (K8s)
* **Infrastructure as Code (IaC):** Terraform, Ansible
* **CI/CD:** GitHub Actions, Jenkins
* **Cloud Platforms:** AWS / Azure / GCP
* **Monitoring:** Prometheus, Grafana

---

## 📂 Repository Structure

| Folder | Description |
